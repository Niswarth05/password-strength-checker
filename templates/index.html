Settings

Change master password

Your vault is re-encrypted with the new password. Backups you made earlier keep their own backup password.

Export an encrypted backup

Saves every entry in one file, encrypted with a backup password you choose. Without that password the file cannot be opened, so keep it safe.

Import a backup

Adds the entries from a backup file. An entry is skipped if you already have one with the same name and username. Nothing is overwritten or removed.
