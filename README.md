# 🔐 Password Security Tool

A beginner-friendly Python cybersecurity project that checks password strength, generates secure passwords, and demonstrates password hashing and verification using bcrypt.

## 🚀 Features

- Password strength checker
- Checks password length
- Checks uppercase letters
- Checks lowercase letters
- Checks numbers
- Checks special characters
- Common-password detection
- Estimated password entropy
- Secure password generator using `secrets`
- Password hashing using bcrypt
- Password verification
- Saves password hashes locally
- Uses `.gitignore` to protect sensitive files

## 🛠️ Technologies Used

- Python 3
- bcrypt
- Git
- GitHub
- Kali Linux
